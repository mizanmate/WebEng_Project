Web Engineering project making a FK Club and Even management System (CEM)

Comprising 4 module
1. Login (Mizan)
2. Club Management
3. Event management
4. attendance

Basic html,PHP and MYSQL local database are used for this project.

**Step-by-Step Guide for the ContributorSync the Fork:**

**Step 1:** Go to your fork on GitHub and click Sync fork, then Update branch to make sure you have the latest code.

**Step 2:** Open Pull Request: Click the Pull requests tab in either your fork or the original repository, then click the green New pull request button.

**Step 3:** Check the Direction, Ensure the repository dropdowns are set correctly: 
        >Base repository: my original repository and main branch.
        >Head repository: Your fork and the specific branch containing your changes.

**Step 4:** Review the changes, look at the file differences at the bottom of the page to confirm you are only sending the intended changes.

**Step 5:** Submit the request by clicking create pull request, write a short title and description explaining what your code does, and click Create pull request again to finish.
